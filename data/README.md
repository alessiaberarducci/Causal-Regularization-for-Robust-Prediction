# Data

- `dataset_rpe.csv`: processed RPE1 data used by
  [Shen, Bühlmann, and Taeb](https://arxiv.org/abs/2307.10299).
- `lt_interventions_standard_v1/`: Causal Chamber light-tunnel data by Gamella,
  Peters, and Bühlmann
  ([source](https://github.com/juangamella/causal-chamber),
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).
